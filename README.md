# 🎯 Number Guessing Game

A simple Number Guessing Game built with Python, FastAPI, HTML, CSS, and JavaScript.

## 🎮 Live Demo

Live Demo: [Play Number Guessing Game](https://MalikZeshan.pythonanywhere.com)

## 📌 About The Project

This is a beginner-friendly web-based Number Guessing Game.

The computer generates a random number between 1 and 100.

The player has 7 attempts to guess the correct number.

The game gives hints:

- ⬆️ Too low
- ⬇️ Too high
- 🎉 Correct
- 😢 Game Over

## 🚀 Features

- Player name
- Favorite game input
- Random number generation
- 7 attempts
- Higher and lower hints
- Correct guess message
- Game over message
- New game option
- Web-based interface
- Python backend
- FastAPI API

## 🛠️ Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Uvicorn
- Jinja2
